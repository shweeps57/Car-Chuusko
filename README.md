Car Chuusko

A simple desktop application built using Python that recommends cars based on user preferences and allows side-by-side comparison with visual insights.

⸻

-> Overview

Car Chuusko helps users find suitable cars by analyzing multiple factors such as:
	•	Performance
	•	Comfort
	•	Features
	•	Safety
	•	Mileage
	•	Budget

It ranks available cars and shows:
	•	Top recommendations
	•	Least suitable options
	•	Side-by-side comparison between selected cars
	•	Visual comparison using graphs

⸻

-> Tech Stack
	•	Python
	•	Tkinter – GUI
	•	Pandas – Data handling
	•	Matplotlib – Data visualization
	•	NumPy – Mathematical calculations for charts

⸻

-> How It Works
	1.	User selects preferences using sliders and dropdowns
	2.	A weighted scoring system ranks all cars
	3.	Top 4 and bottom 4 cars are displayed
	4.	User selects any 2 cars
	5.	App shows:
	•	Detailed comparison
	•	Performance table
	•	Additional stats
	•	Radar chart visualization

⸻

 Features
	•	 Personalized car recommendations
	•	 Weighted scoring algorithm
	•	 Worst match highlighting
	•	 Side-by-side comparison
	•	 Radar chart visualization
